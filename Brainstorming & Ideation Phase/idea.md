# Brainstorming & Ideation Phase

## Project Title
Automated Ticket Classification System using ServiceNow

## Problem Statement
Educational institutions receive 100+ helpdesk tickets daily. Manual analysis and categorization is time-consuming and causes delays.

## Proposed Idea
Automate ticket classification using ServiceNow Flow Designer to read Short Description and auto-assign Category (Network, Hardware, Software, General) based on keywords.

## Benefits
- Saves manual effort
- Reduces errors
- Faster response to students
- Improves helpdesk efficiency

## Target Users
Students, Faculty, IT Support Team
